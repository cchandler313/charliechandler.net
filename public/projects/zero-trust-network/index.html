Zero-Trust Home Network.

A practical security-lab project focused on reducing implicit trust between network zones, hardening remote access, and making useful activity visible enough to investigate.

NetworkZero TrustTailscaleCloudflareLoggingIn progress

Goal

Build a segmented environment where access is granted because a user, device, and service need it, not simply because two things happen to sit behind the same perimeter.

Design principles

  • Separate trusted clients, servers, management, IoT, guest, and lab workloads into deliberate zones.
  • Default to narrow inter-zone access rather than broad east-west reachability.
  • Keep remote services off the public internet wherever a private overlay or identity-aware proxy is a better fit.
  • Centralize firewall, authentication, host, and service telemetry that can answer useful investigation questions.
  • Document exceptions so temporary access does not quietly become permanent architecture.

Architecture

The final writeup will include the real network diagram, trust boundaries, traffic flows, remote-access paths, management plane, logging pipeline, and the decisions behind each exception.

Security questions this project should answer

  • What can a compromised IoT device reach?
  • What can a remote user reach before and after identity checks?
  • Which management interfaces are reachable from ordinary client networks?
  • Can I reconstruct who connected, from where, to what, and when?
  • Which controls fail open when an upstream identity or overlay service is unavailable?

Project status

Foundation and architecture work in progress. This page is the live shell for the eventual full build log.

Build checklist

Document current network and trust boundaries
Define VLAN and zone policy
Harden management access
Design secure remote access
Centralize useful telemetry
Validate attack-path assumptions

# charliechandler.net

Static portfolio dashboard for Charlie Chandler.

## Files

- `index.html` - main site
- `assets/css/styles.css` - site styles
- `assets/js/main.js` - small navigation/year script
- `resume.pdf` - optional resume file, add this yourself so the resume button works

## Cloudflare Pages settings

Because this is a plain static site:

- Framework preset: None
- Build command: leave blank
- Build output directory: `/` or leave blank for Direct Upload

## Edit quick spots

- Contact links are near the bottom of `index.html`.
- LinkedIn currently uses a placeholder URL.
- Add your actual resume as `resume.pdf` in the project root.
